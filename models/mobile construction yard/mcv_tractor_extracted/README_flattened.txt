MCV Tractor Flattened Variants

Primary flattened version:
- mcv_tractor_flattened.glb / .obj
- Flattened most non-exhaust surfaces into more planar shapes while keeping the exhaust tube region curved.
- Based on the prior simple tractor extraction and intended as the recommended balance.

Stronger flattened version:
- mcv_tractor_flattened_strong.glb / .obj
- More aggressively flattened/blockified.

Origin versions:
- *_origin.glb versions move the mesh so max X = 0, min Y = 0, and Z is centered around 0 for easier modeling/alignment.
